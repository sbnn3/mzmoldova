🔑 Token GitHub (o singură dată)

Ca să poată publica direct pe site, pagina are nevoie de un token personal de GitHub cu acces de scriere doar la repo-ul sbnn3/mzmoldova. Token-ul rămâne salvat doar în browserul tău (nu e trimis nicăieri altundeva decât direct către GitHub) — îl generezi din GitHub → Settings → Developer settings → Fine-grained tokens, cu acces limitat la repo-ul mzmoldova și permisiunea Contents: Read and write.

Niciun token salvat momentan pe acest dispozitiv.
